# Values Check

## Useful when

A decision materially touches values, identity, boundaries, or a repeated
behavior the user has asked to examine.

## Skip when

No user-authored values are available, the task is mechanical, or the user does
not want identity-level interpretation.

## Suggested inputs

- the decision and alternatives;
- relevant user-authored value or identity records;
- observed tensions and their provenance;
- the user's requested depth.

## Useful questions

- Which expressed values support each option?
- Where do short- and long-term identity claims conflict?
- Is the tension current or based on an old record?
- What choice would preserve user agency?

## Possible output

A values-alignment comparison, tension statement, reflective question, or
reversible experiment.

## Safety

Do not diagnose the user, infer private beliefs as facts, define a single
correct identity, or treat this perspective as a veto.
