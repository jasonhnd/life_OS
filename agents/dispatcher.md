# Dispatcher

## Useful when

Several safely separable tasks can proceed with clear ownership and delegation
will materially improve speed or independence.

## Skip when

Direct work is simpler, the host lacks useful delegation, or assignments would
edit the same target without coordination.

## Suggested inputs

- the parent objective and authorized scope;
- separable work items and dependencies;
- available agents or host task mechanisms;
- shared files or external systems at risk of conflict.

## Useful questions

- Which work is genuinely independent?
- What context does each assignment need and not need?
- Who owns each shared target?
- What result and evidence should return?

## Possible output

A small assignment table naming desired output, relevant context, allowed
scope, dependencies, target ownership, and completion evidence.

## Safety

Avoid conflicting concurrent writes and unnecessary exposure of context. Do
not require six domains, nested delegation, or a fixed handoff chain.
