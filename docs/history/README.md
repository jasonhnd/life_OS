# Historical Archive

Everything below `docs/history/` is superseded evidence. Historical files may
contain fixed agent chains, mandatory status lines, hooks, commands, Git
assumptions, real paths recorded in earlier releases, or other behavior that is
not part of Life OS v1.11.

The repository-root `SKILL.md` is the sole universal runtime authority. Current
user documentation lives under `docs/` outside this directory.

## Collections

- `architecture/`, `cortex/`, and `specs/` — v1.7 architecture and
  specifications;
- `v1.10-command-surfaces/` — retired slash commands and fixed prompt
  workflows;
- `v1.10-hosts/` — retired host-neutral universal agent contract;
- `v1.10-runtime-specs/` — retired active references and ritual contracts;
- `v1.10-evals/` — process-prescriptive scenarios and fixtures;
- `v1.10-current-docs/` — user and developer documentation superseded by
  v1.11;
- `i18n-v1.10/` — superseded Chinese and Japanese mirrors;
- `v1.10-internal-records/` — RFC, release-note, compliance, and internal
  examples from the earlier architecture;
- `CHANGELOG-v1.10-and-earlier.md` — release history before v1.11.

Historical inbound links may retain their original paths. They are provenance,
not current navigation or authority.
