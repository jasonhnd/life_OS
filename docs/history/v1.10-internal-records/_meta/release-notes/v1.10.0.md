# Life OS v1.10.0 — Production-feedback hardening

Fixes all four meta-issues filed from ~4 months of daily production vault use (#1 #2 #3 #4). Spec + agent behavior only — no vault-data migration.

## Model-tier dispatch policy (#1 A1)

- New `references/model-dispatch-policy.md`: **judgment / execution / batch** capability tiers with complete minimum-tier tables for all 24 agents and every maintenance job.
- **No silent fall-through**: judgment-tier work on an unavailable frontier model defers with "requires a frontier session" — it never approximates on a weaker model.
- Weak-model dispatch orders must be lookup-table form (explicit file list, mechanical steps, zero open judgment, grep-verifiable acceptance) — `agents/dispatcher.md` §Weak-Model Dispatch Mode.
- Tier→model binding lives in ONE mapping table; `opus`/`sonnet`/`haiku` are tier aliases; versioned model IDs are forbidden repo-wide.

## Maintenance ledger (#1 A2)

- New `meta/maintenance-ledger.md` (`job / cadence / last_run`) — every `scripts/prompts/*` job stamps it on completion (all 26 jobs updated).
- Session start reads one file, surfaces **at most 3 overdue lines**, nudge-only — never auto-runs. Closes 7-day patrol gaps / 13-day-late monthly patrols / +60-entry index drift observed in production.

## Hook layer retired for real (#2)

- Ownership resolved (option c): the bash hook layer is retired — not an optional module, not externally owned. Command-safety gating belongs to the host platform's permission system.
- `/install-agents --refresh` step 4.5 removes legacy `settings.json` registrations + script files (one confirmation, every removal listed, idempotent). `/version-check` warns on residual/duplicate registrations.
- Gatekeeper false positives (absolute-path `rm` flagged as root deletion, blanket `python3 -c` block, "verify" substring tripping the no-verify blocker, self-defeating env-var bypass) disappear with the removal.

## Concurrency & bulk-scale governance (#3)

- **bulk-ingest** (`scripts/prompts/bulk-ingest.md`): batches >20 files stage in quarantine, manifest before routing, 30-file waves with per-wave index registration, mechanical zero-unrouted completion.
- **Multi-window protocol** (`references/multi-window-protocol.md`): unclaimed outbox items must be adopted or archived — none survives two session starts undecided; sessions declare write scope; `git add -A` forbidden on a shared vault; cross-window awareness line at session start.
- **Flat fan-out**: bulk fan-out is depth-1 only (grandchild completion notifications route only to the main loop — intermediate parents stall forever); serial 3-4-worker waves; regression fixture `rc-nested-fanout-stall`.

## Platform hardening (#4)

- **user-patterns durability**: `user_patterns_path:` override in `meta/config.md`; default vault-resident `meta/user-patterns.md` (versioned, synced, patrol-visible); AUDITOR Mode 2 checks staleness / near-duplicates / contradictions.
- **Degradation-safety eval axis**: `/run-eval --tier`, `min_model_tier:` scenario frontmatter, generated `docs/evals/tier-matrix.md`, `/verify-release` check 12 blocks fail-at-declared-floor.
