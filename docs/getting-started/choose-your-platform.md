# Choose a Platform

Choose an AI host that can read the Life OS `SKILL.md`. Filesystem access is
needed for persistent local Markdown work; other capabilities are optional.

| Capability | What it enables |
|---|---|
| Conversation only | Analysis and planning without durable Life OS memory |
| Local filesystem | Full Mode with an explicitly bound second-brain |
| Shell or CLI | Efficient model-selected inspection and execution |
| Subagents | Optional independent or specialist work |
| Connectors and apps | Authorized interaction with external systems |
| Git | Optional history and synchronization |

Different hosts may use different methods while preserving the same Life OS
semantics. A host does not fail merely because it lacks subagents or Shell.
