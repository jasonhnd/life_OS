# First Session

There is no fixed first-session ceremony.

## Conversation-only

State your objective and supply the context you want considered. Life OS can
answer, plan, research, or compare options without durable storage.

## Full Mode

Select one local Markdown directory and explicitly approve it as the
second-brain. State whether the session may write.

The model should inspect only the bound scope needed for the objective. It
should preserve the existing structure and create only relevant records.

## Good opening requests

> Review the three options below and recommend one.

> The local directory I selected is my read-only second-brain for this session.
> Use only the project note I name.

> Bind my selected local Markdown directory read/write. Help me plan this
> project and save the agreed plan after we decide.

The user may select a theme, but useful work never waits on theme selection.
