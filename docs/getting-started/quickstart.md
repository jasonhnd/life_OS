# Quickstart

After your host can read `SKILL.md`, begin in natural language:

> Help me decide what to prioritize this week. Ask only questions that could
> materially change the recommendation.

That request needs no theme, slash command, fixed agent chain, or persistent
workspace.

For persistent use:

1. select a local Markdown directory;
2. explicitly bind it and state read/write access;
3. name the record or outcome you want;
4. ask Life OS to save the result when appropriate.

Example:

> Use the local Markdown directory I selected as my read/write second-brain for
> this session. Review the project note I name, help me decide the next move,
> and save the decision beside that project.

This does not authorize a commit or push unless the request also includes it.
