# What Is Life OS?

Life OS is a set of portable Markdown instructions and optional templates that
helps an AI model support decisions, plans, reflection, and durable personal
knowledge.

The user provides the objective and scope. The model chooses the method based
on the task and current host capabilities. It may answer directly, use tools,
inspect authorized context, or use specialist perspectives.

Persistent use requires one explicitly bound local Markdown second-brain. Git
is optional. Without a binding, useful conversation-only assistance remains
available.

Life OS does not simulate a mandatory bureaucracy. Agent and theme names are
optional ways to structure analysis and presentation.
