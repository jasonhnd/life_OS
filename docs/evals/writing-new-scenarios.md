# Writing Conformance Scenarios

A useful scenario defines:

- a synthetic setup and clear user objective;
- observable required outcomes;
- allowed variation in tools and orchestration;
- concrete failure examples;
- evidence that would support a verdict.

Do not require exact agent names, step counts, headings, emoji, status lines, or
tool sequences unless the user request itself makes that behavior material.

Keep personal data and real second-brain paths out of fixtures and evidence.
