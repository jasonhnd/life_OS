# Second-Brain Overview

The second-brain is the user's persistent local Markdown workspace. It may
contain any readable organization that serves the user's needs.

Life OS must be explicitly bound to the directory before claiming Full Mode or
persistent memory. The binding, not the presence of Git or a conventional file
tree, defines the authorized persistence boundary.

Life OS reads existing structure before writing and avoids incidental
normalization. Sensitive identity, health, relationship, and behavioral records
receive appropriately narrow context handling.

See [Binding a directory](setup-backends.md) and
[Storage and sync](../storage-and-sync/sync-protocol.md).
