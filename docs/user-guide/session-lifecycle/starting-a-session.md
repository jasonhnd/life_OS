# Starting a Session

Start by saying what you want to accomplish.

If persistent context matters, use an existing explicit binding or select a
local Markdown directory and bind it. If no binding exists, Life OS continues
in Conversation-Only Mode.

There is no mandatory start sequence, briefing, theme prompt, Git pull,
maintenance scan, agent launch, or fixed number of questions.

The model may inspect relevant bound context when it materially helps. It must
not search unrelated directories, infer a second-brain, or load personal
records simply because they are nearby.
