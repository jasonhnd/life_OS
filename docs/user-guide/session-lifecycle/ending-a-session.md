# Ending a Session

When the user says “done”, “end”, “adjourn”, or an equivalent phrase, Life OS
may summarize and stop.

That language does not authorize:

- writing or bulk archiving;
- Git commit, pull, or push;
- publication or export;
- migration or deletion;
- a fixed archiver, auditor, or advisor sequence.

If the user explicitly asks to save a decision into a bound second-brain, that
scoped write may proceed. If the user asks for an exact Git or publication
action, it remains a separate authorized operation whose success must be
verified.
