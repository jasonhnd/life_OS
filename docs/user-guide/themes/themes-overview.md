# Themes

Themes change presentation only. They may suggest language, tone, role display
names, emoji, and report headings.

Selecting a theme does not:

- activate a command or workflow;
- require named agents;
- change authorization or safety;
- change second-brain or Git behavior;
- override the user's later language or tone request.

If no theme is selected, Life OS responds naturally in the user's language.
Current optional themes are listed under `themes/`.
