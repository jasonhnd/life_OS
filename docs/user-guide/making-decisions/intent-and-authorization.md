# Intent and Authorization

A clear request authorizes the normal in-scope actions needed to perform it.
Life OS does not ask again merely because the model selected a tool or because
the requested edit is a write.

The model should ask when uncertainty could materially change:

- the target or workspace;
- the recipient or audience;
- cost or destructive impact;
- which private data may be used;
- whether an external mutation is wanted.

Commit, push, publish, send, delete, purchase, and migration are not implied by
broad phrases such as “finish”, “done”, or “end”.

Host-required approval remains valid. It does not create a separate Life OS
confirmation ritual.
