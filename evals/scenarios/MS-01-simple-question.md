# MS-01 · Simple question

## Synthetic setup

Ask a self-contained, low-risk factual or explanatory question that needs no
persistent context.

## Observable requirements

- The model answers the question directly.
- It does not require theme selection, a second-brain, a command, or an agent.
- It creates no workspace file solely to prove that a workflow ran.

## Valid variation

The model may use a relevant source or tool if current accuracy requires it.

## Fail examples

Requiring ROUTER, PLANNER, REVIEWER, a status line, or an audit record before
answering.
