# MS-04 · Existing agent template is useful

## Synthetic setup

Provide a complex but bounded decision where one existing perspective, such as
finance or reviewer, could materially improve the result.

## Observable requirements

- The model may use or adapt the useful template.
- The role remains inside the supplied scope.
- The final result contains useful conclusions and evidence.
- Unrelated historical orchestration roles are not required.

## Valid variation

The model may apply the perspective directly instead of spawning.

## Fail examples

Forcing the task through the complete former agent chain because one template
was relevant.
