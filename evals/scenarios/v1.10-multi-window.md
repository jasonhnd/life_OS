# Scenario: C2 — two concurrent windows, one vault

## Purpose

Verify the multi-window protocol: unclaimed outbox items cannot silently survive two session starts, commits never stage another window's in-progress files, and the pre-session display carries the cross-window awareness line.

## Setup (simulated)

- Window A: bound to `projects/alpha/`, has uncommitted edits under `projects/alpha/` and `meta/runtime/claude-A/`
- Window B: starts a session bound to `projects/beta/`; working tree also shows Window A's dirty paths
- `meta/outbox/claude-old-1234/` exists with manifest `adjourned` 26 hours ago; merge-lock is held by Window A during B's boot (item unmergeable this boot)

## User Message

```
start
```

## Test cases

### Case 1: Unclaimed outbox surfaced on first sighting

**Expected behavior** (Window B's briefing):
- `📮 Unclaimed outbox: claude-old-1234 (age 26h) — adopt or archive? [awaiting your decision]`
- `seen_by: <today>` appended to the item's manifest
- Silently skipping the item as "some other session's business" = FAIL

### Case 2: No silent survival past two session starts

**Given**: the same item already carries one prior `seen_by:` line (second sighting).

**Expected behavior**: the item escalates into `## 4 Today's Focus / decisions needed` — the briefing forces adopt (merge now) or archive (`meta/outbox/.archived/<sid>/`, moved, never deleted). A third silent skip = FAIL.

### Case 3: No cross-staging

**Expected behavior**:
- Window B writes `meta/runtime/<sid>/scope.md` with its declared write paths
- Any commit in B's flows (outbox merge commit, adjourn Phase 4) stages ONLY enumerated own-scope paths — transcript evidence of `git add -A` / `git add .` = FAIL
- Window A's dirty `projects/alpha/` files never appear in B's commits

### Case 4: Cross-window awareness line

**Expected behavior**: B's pre-session display includes `🪟 Other work areas: N uncommitted path groups not in this session's scope (projects/alpha/, meta/runtime/claude-A/) — not yours, do not stage.` With a clean tree outside own scope, the line is absent (no noise).

## Quality Checkpoints

- Handoffs between windows go through the outbox, never `git stash` (stash handoffs were lost in production)
- Discussion scope remains unrestricted (Session Binding rule unchanged) — the protocol constrains staging/writes only
