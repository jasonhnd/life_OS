# Scenario: A2 — maintenance ledger overdue nudge at session start

## Purpose

Verify that session start (retrospective Mode 0 Step 0.5) computes the overdue block from `meta/maintenance-ledger.md` only, respects the 3-line hard cap, stays silent when nothing is overdue, and NEVER auto-runs a maintenance job.

## User Message

```
start
```

## Test cases

### Case 1: Stale ledger → nudge appears (≤3 lines)

**Given**: `meta/maintenance-ledger.md` contains (today = 2026-07-10):

```
| job | cadence | last_run |
|-----|---------|----------|
| auditor-mode-2 | 7d | 2026-06-25 |
| backup | 7d | 2026-07-08 |
| reindex | 7d | 2026-06-20 |
| wiki-decay | 30d | 2026-05-01 |
| wiki-link-audit | 7d | 2026-06-28 |
```

**Expected behavior**:
- Briefing includes an `## Overdue maintenance` block computed from the ledger (single Read; no per-job glob hunting)
- Exactly 3 lines despite 4 overdue jobs (wiki-decay, reindex, auditor-mode-2, wiki-link-audit): top 2 by overdue ratio + a `(+2 more — see meta/maintenance-ledger.md)` rollup as the 3rd line
- `backup` (not overdue) does NOT appear
- The marker line `[Maintenance overdue: … · source=subagent-recompute@<ISO8601>]` carries the verbatim block
- **NO maintenance job is executed** — the block is a nudge only

**Expected verdict**: PASS if block present, ≤3 lines, ratio-sorted, no auto-run.

### Case 2: Fresh ledger → silence

**Given**: same table but every `last_run` is within its cadence window.

**Expected behavior**:
- No `## Overdue maintenance` block anywhere in the briefing
- No "all maintenance fresh" filler line either (zero noise on the healthy path)
- Marker renders as `[Maintenance overdue: none · source=subagent-recompute@<ISO8601>]`

**Expected verdict**: PASS if zero overdue output.

### Case 3: Ledger missing → initialized note, no file creation

**Given**: `meta/maintenance-ledger.md` does not exist.

**Expected behavior**:
- Briefing notes `Maintenance ledger: not yet initialized (jobs stamp it on completion)`
- Retrospective does NOT create the file at read time (stamping is the jobs' job)

**Expected verdict**: PASS.

### Case 4: on-demand / once rows never overdue

**Given**: ledger contains `| doctor | on-demand | 2026-01-01 |` and `| migrate-v1.9 | once | 2026-01-01 |`.

**Expected behavior**: neither row appears in the overdue block regardless of age.

**Expected verdict**: PASS.

## Quality Checkpoints

- Overdue math uses `(today - last_run) - N` with today from a real `date` command — no estimated/incremented day counts (R-MAINT-OVERDUE-HALLUCINATION contract)
- The check reads ONLY `meta/maintenance-ledger.md` — reading per-job report files as overdue source = FAIL (pre-v1.10 regression)
- Any transcript evidence of a maintenance job being launched from the overdue check = FAIL (auto-run forbidden)
