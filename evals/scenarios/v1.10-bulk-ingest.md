# Scenario: C1 — bulk import stays inside the governance chain

## Purpose

Verify that a large batch import routes to `bulk-ingest` (not the trickle inbox path), stages in quarantine, writes the manifest BEFORE routing, registers indexes per wave, and completes only on a mechanical zero-unrouted check.

## User Message

```
I exported 50 notes from my old notes app — import them all into my second brain.
```

## Test cases

### Case 1: >20 files routes to bulk-ingest — PASS

**Expected behavior**:
- ROUTER routes to `scripts/prompts/bulk-ingest.md` (50 > 20 threshold), NOT the normal inbox path
- All 50 files land in `sources/ingest-<date>-<time>/` first — zero files written directly into `wiki/`, `projects/`, `areas/`, `meta/`
- `MANIFEST.md` (50 rows, all `status: staged`) exists BEFORE any file is routed

### Case 2: Per-wave registration — PASS

**Expected behavior**:
- Routing proceeds in waves of ≤30 (50 files → 2 waves)
- After wave 1, its routed wiki/project entries are ALREADY registered in `wiki/INDEX.md` / owning `index.md` — registration at batch-end-only = FAIL (unregistered drift would exceed one wave)
- Low-confidence classifications route to `inbox/` for human triage, not guessed into live trees

### Case 3: Mechanical completion — PASS

**Expected behavior**:
- Completion declared ONLY when `grep -c '| staged |' MANIFEST.md` == 0 AND `routed_files == total_files`
- With 1 unrouted row remaining: the job reports the exact row and keeps the batch open — declaring "done" = FAIL
- On completion: ledger stamped (`| bulk-ingest | on-demand | <date> |`)

### Case 4: Flat fan-out respected

**Expected behavior**: if waves are parallelized, workers carry the constraint `You MUST NOT spawn subagents`; no transcript evidence of depth-2 spawning (per `rc-nested-fanout-stall`).

## Quality Checkpoints

- 0 files present on disk but absent from indexes at completion (the ~400-file production failure mode)
- Manifest survives at `sources/<batch-id>/MANIFEST.md` as provenance after completion
- Simulated 50-file batch reconciles: manifest `total_files: 50` == routed rows == index registrations
