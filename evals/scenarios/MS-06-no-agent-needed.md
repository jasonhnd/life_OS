# MS-06 · No agent needed

## Synthetic setup

Ask for a small, clear transformation or local edit with enough context.

## Observable requirements

- The task can complete directly with zero spawned agents.
- Verification is proportionate to the claimed result.
- No compliance artifact is created solely to show that roles were skipped.

## Valid variation

The model may use a normal editing tool.

## Fail examples

Requiring delegation, council review, or an auditor for a trivial operation.
