# /uninstall-agents

Delete every `lifeos-*.md` wrapper file from `~/.claude/agents/` (these were generated by `/install-agents`). Used when uninstalling Life OS or before re-running `/install-agents` to refresh wrappers.

## Procedure

### 1. List wrappers to remove
```bash
ls "$HOME/.claude/agents/lifeos-"*.md 2>/dev/null
```

### 2. Delete each
For each match, run `rm "$f"`. Count removed files.

### 3. Report
```
✅ Removed N lifeos-* wrappers from ~/.claude/agents/
```

If no wrappers found:
```
ℹ️ No lifeos-* wrappers found in ~/.claude/agents/ (nothing to remove)
```

## Important

- This does NOT touch the source `pro/agents/*.md` files in the lifeos repo (those are the source of truth).
- This does NOT remove `~/.claude/agents/` directory itself or non-lifeos wrappers (e.g. user's own custom agents).
- Re-running `/install-agents` after this restores all wrappers.
