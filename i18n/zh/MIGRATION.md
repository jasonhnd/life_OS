# 迁移到 Life OS v1.11

v1.11 是一次架构调整：`SKILL.md` 成为唯一通用运行时权威，固定命令、固定
agent 链、会话仪式和 Git 前置条件被退役。

## 兼容内容

- 现有 v1.9/v1.10 Markdown 数据仍可读取；
- 原有目录和 frontmatter 不需要自动改写；
- 旧触发词和斜杠命令名称仍可按自然语言意图理解；
- Git 管理的第二大脑仍然可用；
- 原有 agent 名称仍可作为可选视角。

升级 Life OS 本身不授权读取或修改真实第二大脑。

## 升级后

1. 用适合当前宿主的方式更新 Life OS Markdown 文件；
2. 确认宿主可以读取根目录 `SKILL.md`；
3. 清除仍把历史命令或 prompt 当成必需入口的宿主配置；
4. 用自然语言开始，不需要运行历史迁移命令。

使用 Git 更新一个开发仓库只是安装方式之一，不是 Life OS 的运行时要求。

## 绑定第二大脑

完整模式需要用户明确选择并批准一个本地 Markdown 目录。说明它是第二大脑、
访问权限是只读还是可读写，以及绑定是否只在本次会话有效。

不要把 Life OS 开发仓库绑定成第二大脑；不要根据 `.git`、`SOUL.md` 或目录名
自动推断；不要扫描其他目录寻找第二大脑。

没有绑定时继续使用仅对话模式。

## 可选的数据迁移

只有用户明确要求结构迁移时才执行。迁移应确定目标、预览重要变化、保护用户
内容、选择适当的恢复证据，并在写入后验证。

Git 可以提供恢复证据，但不是前提。安装、更新、开始、保存、完成和结束都不
自动授权批量迁移。

本地修改、commit、push、创建 PR、打 tag 和发布版本是彼此独立的操作。
