# Life OS v1.11 への移行

v1.11 では `SKILL.md` が唯一の共通ランタイム権威になります。固定コマンド、
固定 agent チェーン、セッション儀式、Git 前提は廃止されます。

## 互換性

- v1.9/v1.10 の Markdown データは引き続き読めます；
- 既存のディレクトリや frontmatter は自動変換されません；
- 旧トリガー語やスラッシュコマンド名は自然言語の意図として理解できます；
- Git 管理の second-brain も利用できます；
- 既存 agent 名は任意の視点として残ります。

Life OS 製品の更新は、実際の second-brain を読む・変更する許可ではありません。

## 更新後

1. ホストに合う方法で Life OS の Markdown ファイルを更新する；
2. ホストがルートの `SKILL.md` を読めることを確認する；
3. 歴史的なコマンドや prompt を必須にするホスト設定を外す；
4. 自然言語で開始し、過去の移行 prompt を自動実行しない。

Git による checkout 更新はインストール手段の一つであり、ランタイム要件では
ありません。

## Second-brain のバインド

Full Mode では、ユーザーが正確なローカル Markdown ディレクトリを選び、
読み取り専用か読み書き可能かを明示します。

Life OS 開発リポジトリを second-brain にしないでください。`.git`、
`SOUL.md`、ディレクトリ名から推測せず、他の場所を探索しません。

バインドがなければ Conversation-Only Mode を使います。

## 任意のデータ移行

構造移行は、ユーザーが明確に依頼した場合だけ行います。対象を確定し、重要な
変更を事前表示し、ユーザーデータを保護し、適切な復旧証拠を選び、変更後に
検証します。

Git は復旧証拠として利用できますが必須ではありません。インストール、更新、
開始、保存、完了、終了は一括移行を意味しません。

ローカル変更、commit、push、PR 作成、tag、release 公開は別々の操作です。
