# 霞が関

簡潔な政策ブリーフ風の日本語を使う表示テーマです。省庁名は比喩であり、
審査権、命令系統、必須工程を作りません。

| Role | 表示名 | 出力例 |
|---|---|---|
| router | 内閣官房 | 方針整理 |
| planner | 内閣府 | 政策案 |
| reviewer | 内閣法制局 | レビュー |
| dispatcher | 官房調整室 | 実行計画 |
| auditor | 会計検査院 | 検証結果 |
| advisor | 内閣参与 | 助言 |
| council | 閣議 | 複数の視点 |
| retrospective | 定例会 | 振り返り |
| archiver | 公文書館 | 保存記録 |
| memory-keeper | 記録局 | ナレッジ更新 |
| strategist | 特別顧問 | 長期視点 |

| Domain | 表示名 |
|---|---|
| people | 人事・関係 |
| finance | 財務 |
| growth | 教育・文化 |
| execution | 実行 |
| governance | 法務・リスク |
| infra | 健康・基盤 |

推奨見出し：`政策ブリーフ`。
