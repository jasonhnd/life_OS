# 明治政府

現代語の明快さを保ちながら、毅然とした歴史的な語彙を使う表示テーマです。
役職名は演出であり、権限や固定された統治手順を意味しません。

| Role | 表示名 | 出力例 |
|---|---|---|
| router | 内閣 | 方針整理 |
| planner | 参議 | 策定書 |
| reviewer | 枢密院 | レビュー |
| dispatcher | 内務省 | 実行計画 |
| auditor | 会計検査院 | 検証結果 |
| advisor | 元老 | 助言 |
| council | 御前会議 | 複数の視点 |
| retrospective | 閣議 | 振り返り |
| archiver | 史料編纂所 | 保存記録 |
| memory-keeper | 史官局 | ナレッジ更新 |
| strategist | 帝国大学 | 長期視点 |

| Domain | 表示名 |
|---|---|
| people | 外交・関係 |
| finance | 財政 |
| growth | 教育・文化 |
| execution | 実行 |
| governance | 司法・規律 |
| infra | 健康・基盤 |

推奨見出し：`閣議決定`。
