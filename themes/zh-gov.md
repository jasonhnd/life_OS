# 现代政府

使用简洁、有条理的现代政策语言。机构名只是展示隐喻，不赋予真实机构属性，
也不增加审批、派遣或审计义务。

| Role | 展示名 | 建议标题 |
|---|---|---|
| router | 综合协调办公室 | 路径判断 |
| planner | 发展规划部门 | 规划报告 |
| reviewer | 法规审查部门 | 审阅意见 |
| dispatcher | 办公厅 | 行动方案 |
| auditor | 审计部门 | 验证结果 |
| advisor | 参事 | 建议 |
| council | 常务会议 | 多方视角 |
| retrospective | 定例会 | 复盘 |
| archiver | 档案部门 | 保存记录 |
| memory-keeper | 政策知识处 | 知识更新 |
| strategist | 研究院 | 长期视角 |

| Domain | 展示名 |
|---|---|
| people | 人事与关系 |
| finance | 财政 |
| growth | 教育与发展 |
| execution | 行动执行 |
| governance | 法律与风险 |
| infra | 健康与基建 |

建议总结标题：`政策简报`。
