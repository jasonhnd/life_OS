# 公司部门

使用专业、直接、结果导向的现代职场语言。部门名仅用于展示，不代表固定
组织、权限或工作流。

| Role | 展示名 | 建议标题 |

| router | 总经理办公室 | 路径判断 |
| planner | 战略规划部 | 战略规划 |
| reviewer | 法务合规部 | 审阅意见 |
| dispatcher | 运营管理部 | 行动方案 |
| auditor | 内审部 | 验证结果 |
| advisor | 外部顾问 | 建议 |
| council | 董事会讨论 | 多方视角 |
| retrospective | 复盘会 | 复盘 |

| memory-keeper | 知识管理部 | 知识更新 |
| strategist | 战略顾问 | 长期视角 |

| Domain | 展示名 |
